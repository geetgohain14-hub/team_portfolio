# Cura Tech Media — Team Portfolio & Pitch Web Application

A modern, high-density Bento-grid team portfolio and investor pitch website built for **Cura Tech Media** to partner with **Cura Tech Engineering** in Guwahati and Assam.

![Bento Grid Aesthetic](https://img.shields.io/badge/Design-Bento_Grid_Sharp-orange)
![Tech Stack](https://img.shields.io/badge/Stack-React_19_|_TypeScript_|_Tailwind_v4_|_Vite-slate)
![Status](https://img.shields.io/badge/Status-Pitch_Ready-green)

---

## 🌟 Key Features

- **Sharp Bento Grid Architecture**: Square and rectangular modules with crisp borders, zero whitespace, and modern high-contrast typography.
- **Color Palette**: Dominant Crisp White & Slate-900 with rich Terracotta / Orange-Brown highlights (`#c85a17` / `#ea580c`).
- **Interactive Specialist Roster**: Interactive profile cards for all 5 team members with detailed CV modals parsed from official documents.
- **Visual Drone Showcase**: 4 aerial drone shot types with an embedded 4K sample video preview modal.
- **Customer Conversion Funnel**: 4-step lead pipeline connecting social reach directly to WhatsApp inquiries and site consultations.
- **7-Day Weekly Calendar**: Live interactive content planner with day/format filtering and a real-time content idea injector.
- **18 Pitch Sections**: Comprehensive strategy breakdown including market problem, vision, content pillars, posting cadence, campaign ideas, commercial ROI, workflow loop, and influencer briefing systems.

## 🛠️ Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/geetgohain14-hub/team_portfolio.git

# Navigate into the project folder
cd team_portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will run locally at `http://localhost:5173/`.

---

## 📦 Production Build

```bash
npm run build
```

The compiled output will be generated in the `dist/` directory.
